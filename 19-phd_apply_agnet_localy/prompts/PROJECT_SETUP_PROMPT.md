# Project Setup Prompt

Copy this once into your ChatGPT Project after uploading this package and your CV/profile.

```text
Use the Professor Outreach Agent v2 package as my workflow instructions.

My uploaded CV/profile is the only source for my personal background.
Do not invent any facts about my education, publications, skills, awards, dates, work experience, or research experience.

For each university batch:
- search public official university/faculty pages first
- find 10–20 relevant professors
- collect public emails only
- create professors.csv
- create personalized email drafts
- create honest tailored CV drafts
- create send_queue.csv
- create send_queue.html
- create batch_summary.md
- return everything as a ZIP

Do not auto-send emails.
Do not ask for Gmail credentials.
Do not claim professors are accepting students unless the source explicitly says so.
Mark missing emails or uncertain information clearly.
```
