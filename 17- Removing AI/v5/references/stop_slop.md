# Stop Slop — Anti-AI Pattern Rules

Source: stop-slop v1 (Hardik Pandya, MIT). Applied at Phase 4, Language Polishing, Style Gate.

## Core Rules

1. **Cut filler phrases.** Remove throat-clearing openers, emphasis crutches, all adverbs. See `phrases.md`.
2. **Break formulaic structures.** No binary contrasts, negative listings, dramatic fragmentation, rhetorical setups, false agency. See `structures.md`.
3. **Active voice.** Every sentence needs a human subject doing something.
4. **Be specific.** Name the thing. No vague declaratives. No lazy extremes.
5. **Put the reader in the room.** Specifics beat abstractions. "You" beats "People".
6. **Vary rhythm.** Mix sentence lengths. Two items beat three. No em dashes.
7. **Trust readers.** State facts directly.
8. **Cut quotables.** If it sounds like a pull-quote, rewrite it.

## Quick Checklist

Run after every prose block:

- [ ] Any adverbs? Kill them.
- [ ] Passive voice? Find the actor.
- [ ] Inanimate thing with human verb ("the decision emerges")? Name the person.
- [ ] Sentence starts with Wh- word? Restructure.
- [ ] "here's what/this/that" opener? Cut to the point.
- [ ] "not X, it's Y" contrast? State Y directly.
- [ ] Three same-length sentences in a row? Break one.
- [ ] Every paragraph ending punchily? Vary it.
- [ ] Em dash present? Remove. Use comma or period.
- [ ] Vague declarative? Name the specific thing.
- [ ] Narrator-from-a-distance? Put the reader in the scene.
- [ ] Meta-joiners ("the rest of this section…")? Delete.
