# Paper Writing Agent v5

Anti-AI slop checker and rewriter for academic prose — evidence-grounded, four-layer detection.

---

## Quick start (four steps)

### Step 1 — Setup (run once)
```
python run.py setup
```
Installs colorama, nltk, pdfminer, and optionally spaCy (upgrades accuracy to 95%).

---

### Step 2 — Build your personal writing style (optional but recommended)

| Folder | What to put there |
|--------|------------------|
| `scripts/pdfs/` | Your own published papers (PDF or .txt) — 3–10 papers |
| `scripts/reference_papers/` | 2–3 recent papers from your target field (PDF or .txt) |

> **Important:** Put only papers you wrote yourself in `scripts/pdfs/`.
> Do not add papers by others or AI-generated text — the tool will learn the wrong style.

Then run:
```
python run.py style
```

This generates:
- `references/my_writing_style.md` — your sentence patterns, transitions, openings
- `references/domain_vocabulary.md` — current field terminology

Without this step, the tool uses generic academic rules. With it, feedback says
"this is different from YOUR writing" rather than "this is generically AI-like."

---

### Step 3 — Check your paper

**Option A — drag and drop (easiest):**
1. Copy your paper (`.txt` or `.tex`) into the `input/` folder
2. Double-click `run.bat` (Windows) or `./run.sh` (macOS/Linux)
3. Read the report in the `output/` folder

**Option B — command line:**
```bash
python run.py check  my_paper.txt
python run.py check  my_paper.tex          # LaTeX source — commands stripped automatically
python run.py check  my_paper.txt --report # show detailed rewrite hints
python run.py diff   draft_v1.txt draft_v2.txt   # compare two versions
python run.py corpus draft.txt             # compare to your personal corpus
```

---

### Step 4 — Get automatic rewrite suggestions

After checking your paper, run the rewriter to get suggested fixes for every flagged sentence:

```bash
python rewrite_runner.py input/my_paper.txt
python rewrite_runner.py input/my_paper.tex
```

The rewriter reads your paper, detects every issue, and generates 1–2 rewrite
options per flagged sentence using rule-based logic. No API key or internet
connection required.

Output is saved to `output/my_paper_rewrites.txt`.

**What it rewrites automatically:**

| Issue type | What it does |
|---|---|
| Passive voice | "X was evaluated" → "We evaluated X" |
| Zombie noun | "the optimization of X" → "we optimized X" |
| Hedge stacking | Removes all but one hedge word per sentence |
| Context-free comparison | Inserts `[BASELINE]`, `[N]`, `[DATASET]` placeholders |
| Academic filler | Strips openers like "It is worth noting that…" |
| Synonym drift | Replaces all variants with one consistent name |

Tags like `[BASELINE]` and `[METRIC]` are placeholders — fill them in with the
actual numbers and names from your results.

## Folder structure

```
paper-writing-agent-v5/
│
├── input/                    ← DROP PAPERS TO CHECK HERE (.txt or .tex)
├── output/                   ← REPORTS AND REWRITES APPEAR HERE
│
├── scripts/
│   ├── pdfs/                 ← DROP YOUR OWN PUBLISHED PAPERS HERE (style setup)
│   ├── reference_papers/     ← DROP FIELD PAPERS HERE (vocabulary setup)
│   └── corpus/               ← auto-generated (do not edit)
│
├── references/
│   ├── my_writing_style.md   ← auto-generated by run.py style
│   ├── domain_vocabulary.md  ← auto-generated by run.py style
│   ├── academic_phrases.md   ← banned academic AI patterns
│   ├── positive_patterns.md  ← what good prose looks like
│   └── section_norms.md      ← per-section rule relaxations
│
├── slop_lib/                 ← shared Python library (do not edit)
│   ├── analysis.py           ← core analysis engine
│   ├── ai_patterns.py        ← passive ratio, AI methods verbs, formulaic phrases
│   ├── linguistic.py         ← spaCy/regex passive voice and tense detection
│   ├── config.py             ← loads slop_config.yaml
│   └── ...
│
├── slop_config.yaml          ← edit thresholds and field/venue profiles here
├── run.py                    ← main launcher (python run.py help)
├── rewrite_runner.py         ← rule-based rewriter (python rewrite_runner.py input/paper.txt)
├── run.bat                   ← Windows double-click
└── run.sh                    ← macOS/Linux double-click
```

## All commands

```bash
python run.py setup                    # install dependencies (once)
python run.py style                    # build personal writing style

python run.py check  paper.txt         # full slop report
python run.py check  paper.tex         # LaTeX (auto-stripped)
python run.py diff   v1.txt v2.txt     # compare two drafts
python run.py rhythm section.txt       # rhythm-only analysis
python run.py corpus draft.txt         # vs personal corpus baseline
python run.py latex  paper.tex         # section-by-section LaTeX check
python run.py abstract abstract.txt    # abstract structure check
python run.py contrib paper.txt        # contribution bullet analysis

python rewrite_runner.py input/paper.txt   # generate rewrite suggestions
```

Common options for `run.py check`:
```
--report          Detailed rewrite hints
--json            Machine-readable output
--threshold N     Pass score (default from slop_config.yaml or 70)
--field NAME      cs_ai | biomedical | social_science
--venue NAME      acl | neurips | arxiv
```

## Detection layers

| Layer | What it catches |
|-------|----------------|
| Generic stop-slop | adverbs, passive, binary contrasts, throat-clearing |
| Academic phrases | announcement openers, false humility, hedge stacking, contribution inflation |
| Academic structures | "organized as follows", chronological related work, conclusion theatre |
| Rhythm (quantitative) | sentence-length StdDev, paragraph shape, echo detection, starter entropy |
| AI patterns | passive ratio, AI methods verb density, formulaic phrase clusters |
| Linguistic | spaCy passive voice (95% accuracy), tense consistency, agency |

## Tuning (slop_config.yaml)

Edit `slop_config.yaml` to adjust for your field or venue:

```yaml
threshold: 70        # default pass score

fields:
  biomedical:
    thresholds:
      hedge_density: 4        # bio papers hedge more
      passive_ratio_warn: 0.40

venues:
  acl:
    threshold: 75             # ACL reviewers are strict
```

Select at runtime:
```bash
python run.py check paper.txt --field biomedical
python run.py check paper.txt --venue acl
```
